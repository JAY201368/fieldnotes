THE WORKFLOW

from intent to controlled execution →

A complete
delivery process.

The main agent owns design decisions, scheduling, shared records, integration, and acceptance.

01
REQUIRE

Agree on the outcomes

Preserve the user’s requirements. Confirm scope, requirement coverage, and stage closure criteria before dispatch.

✎
02
DESIGN

Establish the architecture

Define components, interfaces, data and state rules. Resolve contract changes before dependent implementation.

▤
03
PLAN

Build the dependency graph

Create bounded tasks with owned files, explicit behavior, edge cases, acceptance criteria, and a verification plan.

↗
04
DISPATCH

Select and coordinate workers

Choose model and reasoning depth by complexity and risk. Run independent tasks in parallel, with two implementation workers by default.

✳
05
ACCEPT

Review, record, and commit

Review each criterion against the result and applicable evidence. Record the accepted work and create a scoped Git commit.

✓
06
TRANSITION

Close and hand off the stage

Reconcile open requirements, confirm closure, and archive the handoff. Plan the next stage using the accumulated project context.

Each worker receives the relevant records, a complete task card, dependency evidence, and its verification plan. The main agent keeps shared records current and reconciles them with the repository when resuming.

NINE WORKER CONFIGURATIONS

Luna · max for bounded routine work.
Sol · medium through max for implementation and integration.
Astra · medium through max for design uncertainty and difficult cross-system reasoning.
